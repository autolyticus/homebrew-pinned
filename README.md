# homebrew-pinned
Pinned brews and casks

## betterdisplaycli
Took waydabber/betterdisplaycli compiled it and made it into a Cask, since I don't want to have xcode 14.0 installed on all of these devices and go through the compilation.


## betterdisplay
Similarly, I wanted to pin and force the version of betterdisplay to be a specific one, so I have one for betterdisplay as well.


## multitimebar
Added cask for MultiTimeBar, a native macOS menu bar app for tracking multiple time zones.

## soundsource
Pinned cask for SoundSource legacy version 5 (v5.9.0) from Rogue Amoeba's legacy archive.
